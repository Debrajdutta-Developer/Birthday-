# Birthday Gift Animation

A static birthday greeting website built with HTML, CSS, JavaScript, and local image assets. The page includes animated visual effects and a personalized birthday presentation.

## Run locally

Open `index.html` in a browser or serve the folder with a static web server.

## Files

- `index.html` — page structure and interactive effects
- `style.css` — visual styling
- Image and GIF assets — decorative elements used by the page
